# Deep-learning--gen-ai-paper-reco
A hands-on collection of 60+ deep learning research paper implementations with practical code and side-by-side technical notes. Covers modern architectures and techniques including Transformers, ViT, Switch Transformer, Adam, AdaBelief, Sophia, GANs, DQN, PPO, CapsNet, and Knowledge Distillation.

Project Summary — Deep Learning Paper Implementations:

This project is a collection of simple PyTorch implementations of deep learning papers and algorithms, with detailed explanations and side-by-side technical notes to make complex concepts easier to understand.

🔥 Main Topics Covered
Transformers & LLMs: Transformer, Transformer-XL, GPT, Switch Transformer, Feedback Transformer, ViT, RoPE, ALiBi, RETRO, etc.

LLMs & Fine-tuning: LoRA, GPT-NeoX, LLM.int8().
Diffusion Models: DDPM, DDIM, Latent Diffusion, Stable Diffusion.

GANs: Original GAN, DCGAN, CycleGAN, WGAN, WGAN-GP, StyleGAN2.

Deep Learning Architectures: LSTM, ResNet, ConvMixer, Capsule Networks, U-Net, HyperNetworks.

Graph Neural Networks: GAT and GATv2.
Reinforcement Learning: PPO and DQN with advanced techniques like GAE, Dueling Networks and Prioritized Replay.

Optimization: Adam, AMSGrad, Noam, RAdam, AdaBelief, Sophia-G.
Normalization: BatchNorm, LayerNorm, InstanceNorm, GroupNorm, DeepNorm.
Other areas: Knowledge Distillation, Adaptive Computation, Uncertainty, activation functions, language-model sampling, and scalable training/inference.

Primary framework: PyTorch
